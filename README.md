## ⚡ Cómo añadir o actualizar enlaces de los vídeos

Dispones de dos formas muy sencillas para actualizar los enlaces:

### Método 1: Desde la propia web (en el navegador)
1. Abre `index.html` en tu navegador.
2. Haz clic en el botón superior o inferior **"⚙️ Gestionar enlaces"** (o en la tarjeta de cualquier episodio).
3. Pega el enlace de YouTube correspondiente al episodio.
4. Haz clic en **"💾 Descargar index.html actualizado"** para guardar el archivo con los nuevos enlaces fijados permanentemente.

### Método 2: Con el script automático de PowerShell
1. Abre el archivo `Lista de videos para el catalogo de AULAXLIX.txt`.
2. Pega las URLs de los vídeos al final de cada línea correspondiente (después del `=`).
3. Guarda el archivo y ejecuta en PowerShell:
   ```powershell
   .\actualizar_enlaces.ps1
   ```
4. Elige la opción **1** para actualizar automáticamente `index.html`. El script también te preguntará si quieres subir los cambios directamente a GitHub.
